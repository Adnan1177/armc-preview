# معرض تصاميم موقع أفكار الريادة

تصميم أولي للعرض فقط — جميع الحقوق محفوظة © 2026 للمهندس عدنان البنا. يُمنع نسخ هذا التصميم أو استخدامه أو تنفيذه لدى أي جهة أخرى أو في أي مشروع آخر دون إذن كتابي مسبق.

## المحتوى

- `index.html` — معرض يجمع كل الشاشات.
- `site/` — الصفحات التسع، ونماذج الصفحة الرئيسية الثلاثة، ونماذج القائمة الرئيسية الثلاثة، ومخطط سير العمل السابق.
- `workflow-new.html` — سير العمل الجديد (الدفع عند الحجز)، ومراحل الطلب في أودو ورسائلها، وطريقة الربط.
- `v1/` — التصميم الأولي (النسخة الأولى).
